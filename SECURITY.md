# Security

Please report a vulnerability privately, through this repository's
[Security tab](../../security/advisories/new) ("Report a vulnerability"), and not in a public
issue or pull request. Say which package and version it affects and how to reproduce it.

We reply within three working days, and say when a fix is released.

## Supported versions

| Package | Fixed in |
| --- | --- |
| `lsquare` on npm | the latest release |
| `lsquare` on PyPI | the latest release |
| `@lsquare/node` | the latest 0.1 release |
